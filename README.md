# unixy2k

A small static page that shows the current UTC date, Unix epoch time, epoch
time in binary, and the remaining time until the Year 2038 problem threshold:
`2038-01-19 03:14:07 UTC`.

## Run locally

Open `index.html` directly in a browser, or serve the directory with any static
file server:

```sh
python3 -m http.server 8000
```
